# United Tower — نظام إدارة البناية والحسابات

نظام ويب متكامل لإدارة عقارات البناية + حسابات بالقيد المزدوج. يعمل محلياً (localhost) بدون أي خدمات خارجية.

## التشغيل
```bash
cd united-tower
npm install        # مرة واحدة
npm run seed       # مرة واحدة: شجرة الحسابات + الأرصدة الافتتاحية + الشقق + مستخدم admin
npm start          # يشغّل الخادم على http://localhost:4000
```
الدخول الافتراضي: **admin / admin123** (غيّرها من شاشة المستخدمين).

## المخزن
قاعدة البيانات ملف واحد: `data/app.db` (SQLite داخل Node — لا تنصيب native).
للنسخ الاحتياطي انسخ ملف `data/app.db`. لإعادة البدء من الصفر احذفه ثم `npm run seed`.

## المديولات
- **لوحة التحكم**: الإشغال، المحصّل، المستحقات، الدفعات المقدمة، تحصيل 12 شهر، أعمار الديون، أعلى المتأخرين.
- **كالندر الشقق**: أخضر=متاح / أحمر=محجوز حسب العقود، بفلتر تاريخ.
- **العقود**: إنشاء، توليد استحقاقات من بداية العقد، إنهاء مبكر (يلغي المستحقات المستقبلية).
- **العملاء / الاستحقاقات / المقبوضات**: سند قبض بتوزيع تلقائي على أقدم المستحقات + دفعة مقدمة (Advance Income) تُطبَّق تلقائياً على الشهر التالي.
- **المصروفات والموردين**: آجل (ذمم دائنة) أو مدفوع، مع ض.ق.م مدخلات.
- **الموظفين**: اسم + راتب، وترحيل رواتب شهري.
- **المالية**: ميزان مراجعة (بنفس أكواد حساباتك)، قائمة دخل، مركز مالي، قيود يومية + قيد يدوي.
- **أعمار الديون**: مدينة ودائنة، 30/60/90/180/+180.
- **كشف حساب شقة/عميل**: حدد الشقة و/أو العميل والفترة؛ لو تركت العميل فاضي يظهر كل من سكن الشقة.
- **استيراد Excel**: عملاء، شقق، عقود، دفعات، مصروفات — مع معاينة قبل الاستيراد.
